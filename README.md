Overview
This repository functions as a technical research archive dedicated to documenting the overarching narrative universe created by Team Salvato.
By analyzing game assets, decompiled Ren'Py scripts, hidden .chr file metadata, and the virtual desktop files inside DDLC Plus!, this repository catalogs the ARG elements that hint at Team Salvato's upcoming horror titles.
